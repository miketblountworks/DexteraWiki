# Dextera Wiki

## Pages

| File | Content |
|------|---------|
| `index.md` | Home / hero |
| `getting-started.md` | Install and first setup |
| `features.md` | Full feature list + how-tos (screenshot-led) |
| `gestures.md` | Navigation gestures |
| `pages.md` | Launcher pages and widgets |
| `settings.md` | Settings map |
| `permissions.md` | Permissions |
| `privacy.md` | Privacy policy |
| `data-deletion.md` | Data deletion |
| `contact.md` | Feature, bug, support, and privacy email |
